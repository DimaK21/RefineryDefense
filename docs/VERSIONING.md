# Версии и сборки

- Версия задаётся одним местом — `version` в [package.json](../package.json), формат
  `MAJOR.MINOR.0`. Новая функциональность — `MINOR + 1`, ломающие изменения сохранения или
  крупный редизайн — `MAJOR + 1`.
- `pebble build` кладёт рядом с обычным `build/drone defence.pbw` копию
  `build/refinery-defense-<версия>.pbw`.
- Та же версия `v<версия>` видна внизу экрана **Settings** — по ней видно, что стоит на часах.
- Релиз: поднять версию в package.json → закоммитить → поставить тег `v<MAJOR>.<MINOR>` на этот
  коммит → собрать.
